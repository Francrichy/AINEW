Watoa huduma (Providers)

“API key ipo” haimaanishi kuwa integration imekamilika. Huduma itaoneshwa tayari tu pale adapter yake inapokuwa imejengwa na kuwekwa active.

Hakuna taarifa bado.

Ukaguzi wa LiveAvatar

Jaribu API key moja kwa moja na hakiki avatars za Ethan/Ngina pamoja na upatikanaji wa sauti. Hakuna API key itakayoonyeshwa.

Bado haijakaguliwa.

fal.ai · Central Media API

Adapter ya Queue API imejengwa. Kila huduma inahitaji model ID, input template ya model hiyo na bei iliyoidhinishwa kabla ya kuwa tayari. Hakuna generation inayowashwa kwa kuweka API key pekee.

Bado haijakaguliwa.

FAL_API_KEY inabaki salama kwenye Render Environment. Model na templates zinabadilishwa hapa chini. Bei za fal.ai zinaweza kuvutwa moja kwa moja kutoka API ya supplier na kubadilishwa kuwa TZS ×3.5. Kagua kiwango cha USD/TZS kwenye Billing Admin. Unit zisizolingana hazitabadilishwa kiotomatiki.

fal.ai · Model na Input Template

Chagua model au andika Model ID maalumu. Rekebisha JSON template kulingana na API schema ya model. Mipangilio inahifadhiwa kwenye database ya Mlimani; huhitaji kurudi Render Environment kila unapobadilisha model.

Ingia kama Admin ili kupakia mipangilio.

Jinsi ya kuunganisha API mpya

Usiweke API key kwenye GitHub, kwenye ukurasa huu, au kwenye ujumbe wa kawaida. Weka key kwenye Render → Environment kama secret, kisha redeploy baada ya code kuwa tayari.
  1. Fungua akaunti ya provider husika na pata API key.
  2. Weka variable iliyoonyeshwa kwenye kadi ya provider kwenye Render Environment.
  3. Hakikisha integration imeandikwa na kujaribiwa; kuweka key pekee hakutoshi.
  4. Thibitisha gharama, bei ya mteja, matumizi na refund kabla ya kuwasha kwa wateja.
