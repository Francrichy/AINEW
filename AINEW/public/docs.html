Mlimani AI API 🌍

API rahisi ya gumzo kwa waendelezaji. Inapatikana kwa mipango ya kulipia. Tengeneza ufunguo kwenye Akaunti kisha Funguo za API. Tumia ufunguo kutoka kwenye seva yako tu, usiuweke kwenye kivinjari au programu ya simu.

Ombi

curl https://www.mlimani.net/v1/chat \
  -H "Authorization: Bearer mlm_XXXXXXXX" \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"Habari! Nieleze kuhusu Mlimani Kilimanjaro."}],"max_tokens":500}'

messages: majukumu system, user, assistant; ujumbe wa mwisho uwe wa user. max_tokens: hadi 2000.

Jibu

{
  "id": "mlm-...",
  "object": "chat.completion",
  "choices": [{"index":0,"message":{"role":"assistant","content":"..."},"finish_reason":"stop"}],
  "usage": {"prompt_tokens":23,"completion_tokens":210,"total_tokens":233,"cost_tzs":1.9}
}

Bei na mipaka

  • Kila ombi linakata gharama halisi (cost_tzs) kutoka kwenye mkopo wa mwezi wa mpango wako.
  • Mkopo ukiisha unapata hitilafu 402. Pandisha mpango au subiri mwezi ujao.
  • Kikomo: maombi 30 kwa dakika kwa kila ufunguo.
  • Hitilafu: 401 ufunguo si sahihi, 403 mpango umeisha, 429 maombi mengi, 502 huduma ina shida.
  • Mlimani AI haitoi maelezo ya kiufundi kuhusu jinsi ilivyotengenezwa.
